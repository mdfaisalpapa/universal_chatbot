Universal Chatbot Phase 1

Embeddable Chat Widget Demo

This page demonstrates the standalone floating chat widget embedded via a single <script> tag. State and session persistence are guaranteed across page refreshes.

Widget Embed Snippet:

<script
  src="/assets/universal_chatbot/widget/chatbot.js"
  data-deployment-key="{{ deployment_key }}"
  data-server-url="{{ frappe.utils.get_url() }}">
</script>

Look at the bottom right corner of this page to interact with the floating chat assistant!
